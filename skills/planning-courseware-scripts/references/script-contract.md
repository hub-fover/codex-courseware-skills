# 脚本与输出契约

## 输入分类

- **事实源**：知识卡、教材、论文、官方文档及用户明确指定的内容基准。
- **视觉参考**：只约束母版、品牌、配色、信息密度和图示语言，除非用户同时将它指定为事实源。
- **课程元数据**：课程名、章节名、受众、品牌、页脚、语言和目标深度。未提供时使用中性说明，不伪造品牌信息。

## 内容基准

在生成目录前，建立可追溯的内部表，至少包含：标准术语、同义表达、公式 LaTeX、变量次序、维度与单位、坐标约定、适用条件、退化条件、原始说法、采用说法、修订理由和来源定位。

处理冲突时：

1. 明确错字可直接修正，但要保留原文与修订记录。
2. 能用可定位教材、论文或官方文档可靠解决的概念问题，采用准确表述并记录依据。
3. 不能可靠解决且会改变教学结论的问题，列入待确认清单并暂停。

## 目录契约

每页只记录：

```markdown
### 第 1 页｜页面标题
- 页码：`1/30`
- 页面类型：单概念
- 核心问题：本页只解决什么？
- 来源材料：K01；R02 Chapter 3
```

页码从 1 连续递增。目录的页面标题、页面类型和核心问题是后续详细脚本的锁定映射。

## 详细脚本契约

每个批次文件声明 `- 当前批次：第 1–5 页`。每页必须按以下顺序包含 13 个顶层字段，字段名不得改写。

**字段语法是契约的一部分。** 每个字段必须使用顶层无序列表 `- 字段名：值`；不得改成 `1. **字段名**：值`、表格或小标题。字段内部的多项内容可使用缩进子列表。

```markdown
### 第 1 页｜页面标题
- 页码：`1/30`
- 页面类型：单概念
- 核心问题：本页只解决什么？
- 教学目标：学生能够用一句话解释本页核心概念。
- 固定母版文字：课程名；章节名；页码 `1/30`。
- 本页文字：标题、正文、图中标注与结论的完整逐字清单。
- 公式与符号：无。
- 预期可见公式：无。
- 视觉方案：使用一个从左向右的主流程，颜色只表示明确的内容语义。
- 本页结论：本页核心概念可由一句准确结论概括。
- 内容来源：K01 上部；R02 Chapter 3
- 禁止添加：无来源结论、超范围主题和伪造参数。
- 核验点：核对标题、术语、来源、图示方向和页码。
```

字段语义如下：

1. **页码**：`n/N`，与目录和批次一致。
2. **页面类型**：如章节导入、单概念、流程、公式几何、对比、工程检查或总结。
3. **核心问题**：一个可回答的教学问题。
4. **教学目标**：学生完成本页后可观察的能力。
5. **固定母版文字**：必须逐字出现的品牌、章节、页脚和页码；未提供的项目写“无”。
6. **本页文字**：学习者可见的准确文案，区分标题、正文、标注和结论。
7. **公式与符号**：LaTeX、变量定义、维度、单位、约定和适用条件；无公式时写“无”。
8. **预期可见公式**：说明实际展示哪些公式及层级；无时写“无”。
9. **视觉方案**：内容图示的结构、空间关系、箭头方向、坐标和颜色语义，不是出图指令。
10. **本页结论**：一句可被复述的最终结论。
11. **内容来源**：精确到卡片区域、教材章节、论文标题/DOI 或官方文档 URL。
12. **禁止添加**：列出容易混入的无来源内容、超范围主题和错误表述。
13. **核验点**：可逐项判定的文字、公式、图示、来源和一致性检查。

## 最终输出

1. `<course>-course-outline.md`：内容基准摘要与完整目录。
2. `<course>-detailed-scripts-01-05.md` 等：每 5 页一批的详细脚本。最后一批也保留完整起止页码，如单页批次使用 `06-06`。
3. `<course>-unified-review-report.md`：一次性记录全部检查项、修正项、通过项与剩余风险。
4. `<course>-unresolved-items.md`：只列真正无法可靠判断的事实问题；没有时明确写“无”。

详细脚本不得留下 `TODO`、`TBD`、`XXX`、`{{...}}`、`[待补]` 或类似占位符。未解决的事实问题必须进入待确认清单，不得悄然混入面向学习者的文案。
